# Robot models (planned)

**Status: no physical BSRA or OP3 model included.** The baseline loads Gymnasium's built-in generic humanoid model automatically via `Humanoid-v5`.

Quinn's team should evaluate and validate a suitable temporary humanoid model, document model provenance/license and conversion steps in `docs/OP3_MODEL_CHECKLIST.md`, and replace it with BSRA's final hardware model when available. External model downloads and large meshes belong in ignored `robot_models/external/` or approved artifact storage, not committed by default.
